# Watch‑Wave

Watch‑Wave is a full‑stack entertainment tracker that allows users to organize, track, and manage their personal movie and TV show watchlists in one place.

Built using: Built with HTML, CSS, JavaScript, TypeScript, Next.js, Node.js, Express.js, and SQL.

---

## Key Features

* Create, view, update, and delete movie and TV show entries
* Maintain personal watchlists with structured data storage
* RESTful backend API for watchlist management

## Getting Started

### Prerequisites

Ensure you have the following installed:

* Node.js (v18 or higher recommended)
* npm or yarn
* A SQL database (MySQL or PostgreSQL)

---

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Idowu-David/watch-wave.git
cd watch-wave
```

2. Install backend dependencies:

```bash
cd backend
npm install
```

3. Install frontend dependencies:

```bash
cd ../frontend
npm install
```

## Running the Application

### Start the Backend Server

```bash
cd backend
npm run dev
```


### Start the Frontend Application

Open a new terminal window, then run:

```bash
cd frontend
npm run dev
```
